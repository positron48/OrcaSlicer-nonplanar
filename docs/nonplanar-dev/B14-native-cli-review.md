successful slice or leak a candidate through an ordinary export action. CLI
setup rejects mixed actions and requires explicit datadir before loading inputs.

return CLI_SLICING_ERROR; the shared report retains all 17 mandatory checks and
export BLOCK. Its stdout contains replay and identities, not candidate G-code.

the original private request factory, retaining every typed role and geometric
choice. Exact float32 vertices, original winding/properties, unsigned ID types,
finite numbers, registries/counts/bytes/depth and duplicate keys are checked.
The existing strict scene grammar is reused. Scene or firmware qualification is
not inferred from a JSON flag. The independent oracle reconstructs original
binary vectors and scans original final decimal bytes into diagnostic movements.

The action captures original JSON/source resources through bounded opaque file
capture; count and aggregate byte limits are checked before resource copying.

deadline. Capture detects file changes during its own read, but does not make
the earlier ordinary import and later read an atomic source snapshot. Full
source-to-plan qualification remains UNKNOWN; that gap cannot grant export.

restores the previous handler and feeds the existing cooperative root. Failed
or cancelled work exposes no completed/partial candidate. Production defaults
are exercised as a separate native owner and compared movement-for-movement
with the real CLI. The original finer packet fixture and negative cases remain.

name only. Unknown loader failures remain ordinary Orca diagnostics; complete
import diagnostic packaging and all CLI operation variants are still pending.

new action. The integration gate enforces offline, fresh isolated directories.

isolated worker before exposing expensive native/CGAL work interactively. Minimal
GUI, complete scene/contact/seams/full fill/later passes, all job motions/order,
source/software/physical qualification and publication remain open. This is
the author's critical review; independent safety review remains pending.
