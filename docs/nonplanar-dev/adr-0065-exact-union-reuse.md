# ADR-0065: reuse exact local union geometry under unchanged budgets

Status: bounded private optimization implemented; Linux verification and independent
review remain pending. Scope: DepositionModel.cpp and analytical material tests.
Original normative files and public runtime/serialized contracts are unchanged.

## Invariant

Within one owned union_integral invocation, reuse immutable exact axial bead
bounds and exact polygon extrema. An actual four-edge axis rectangle must have
alternating nonzero horizontal/vertical edges and CCW orientation before its
intersection and area may use rational coordinate intervals/products. Arbitrary
polygons retain the original clipping and affine-moment path. A bounding box of
an arbitrary polygon never proves material occupancy.

The exact rectangle intersection applies the same original conservative XY
bounds and the exact original partial butt. Partial progress remains the exact
binary64 input as Gmpq; it is never rounded to a new endpoint. Axial whole-cell
longitudinal containment is equivalent to the original positive squared-axis dot
product test. Retain every original packet, real hole and old/current/future
selection. Reuse begin/end for the same finite strip chains only.

For a confirmed rectangle, coordinate moments equal area times its exact
coordinate midpoint. All products/divisions remain rational until the same
outward exact_interval conversion. Exact extrema are reused by concavity and
convex-envelope checks. Directed conversion is monotone, so converting exact
coordinate/reference extrema gives the same lower/upper hull as converting all
vertices first. The original domain area is constant within this invocation.

## Resource and publication boundaries

Caches are local to one captured request; no shared, retained or persisted cache
is introduced. Populate axial data only for original active bead rows within the
already charged evaluation. Existing evaluate/poll calls, cell/depth/work limits,
absolute deadlines, outward precision, cancellation/stale/rounding checks and
publication ownership remain. No margin, loss, default, unsupported fallback,
contact exception or UNKNOWN policy changes. Memory allocation failure retains
original exception-to-UNKNOWN handling; full resource qualification remains B13.

Existing models, geometry, scenes, journal/IR/3MF/profile versions and source
fingerprints are unchanged. No guarded export consumes these proofs as complete
job approval. Runtime numerical guarantees are exact identities in the admitted
shape class, rather than a new approximate integrator or sampled acceptance.

rectangle/stadium sections over an original nonrepresentable partial butt. Both

that endpoint has zero material although a matching future row exists. Existing
rotated/clipped/unequal/holed/current/union/multiplicity/void and budget negatives
remain. Comparison uses all printed Catch expansions, normalizing address tokens
only; it does not claim bitwise verification of unprinted bounds.
