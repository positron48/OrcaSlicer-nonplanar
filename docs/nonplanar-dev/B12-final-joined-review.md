Author review only; independent safety review remains pending.

The new protected types retain the actual final-byte material prefix and their
own captured policy. Exact adjacent record order, endpoint XYZ equality, forward
collinear XY and identical section kind build maximal runs. The entire three-
dimensional top need not have a single slope: every packet retains its own
affine top/gap and final E-derived minimum dose. Pressure, travel, dwell, a turn,
reversal or a section-kind change ends a run. Near-collinear decimal rounding
does not gain an arbitrary tolerance. No old planner/run/contact certificate is
an input to this independent geometry calculation.

This is an explicit synthetic common-run uncertainty model. It does not infer
bonding of independently displaced packets or calibrate pressure disturbances.
Per-event erosion APIs and original refusals remain. The common-run Lower is
the union of minimum-dose packet sections eroded by the original local along/
normal XY plus Z kernel, with strict external butt faces. All growth/loss/
numeric and dose uncertainty values remain. Run AABBs only prune exclusion;
they cannot supply occupied support or contact.

Whole-box projection encloses every query point. Expanding those intervals by
the unchanged kernel, then clipping at exact actual packet boundaries, requires
every complete positive longitudinal slice to be inside its rectangle/stadium.
Closed internal faces do not create an external cap or future material. A
partial current event uses its actual front but its original full-event flux.
Widths/gaps are never averaged. Point slices retain closed-face semantics;
boundaries without a proof remain UNKNOWN. For exclusion, one admissible fixed
translation of the complete query outside the minimum union excludes that query
from the erosion. This finite negative check cannot grant Inside.

The breadth-first cover partitions the complete region, with protected run
owners on each leaf. A missing region or unresolved budget/depth/cell/numeric/
freshness/deadline/cancellation condition prevents a partial certificate.
Original source/material/rate guards plus the new joined-policy guard run before
publication. The joined callback precedes numeric checks, so it cannot change
rounding after the final environment guard. Callback inputs/limits are captured.
Work inherits the preceding prefix/capture; it cannot reset to zero at cover.

Separate 113-bit test replay reads decimal commands directly. It checks actual
run continuity/direction/kinds, actual prefix end, E/flow inversion once, every
expanded complete section slice and total covered longitudinal extent. Union
tests additionally check leaf bounds, disjoint interiors and partition volume.
Original per-event Lower failure and new native front failure remain, alongside
one independent native joined interior proof. Late positive and negative numeric
publication, stale dependencies, caller mutation and exhaustion are exercised.

IDs, keys and nesting. The new CLI requires Lower and shares an original one-
second deadline across replay/material/prefix/run/cover. Selected component
status survives earlier reporting; job remains UNKNOWN/export false. CLI data

identity; no older report is accepted merely because the candidate bytes match.
Full contact/gap/head/route/cap, qualified delivery, platforms and physical work
remain separate obligations.
