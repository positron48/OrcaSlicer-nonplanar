Date: 2026-10-03. ADR-0096. This separate author audit is not independent safety
review; independent review remains PENDING.

## Actual-prefix ownership and order

Reviewed the new factory against existing assessment, bead and append contracts.
Before/list/limits are copied before callbacks. Complete previous material is
mandatory. Only current/immediate original pass indices are admitted. Fixed width
and original direction come from the private captured hatch owner. Each support
and dose source is the exact current prefix, and each append retains all previous
rows/origins/owners. Duplicate same-area requests fail on recomputed actual
material. All before/after/path ownership remains private and immutable.

Retaining a completed local path and advancing an index is not evidence of a
complete filled layer. Connector Travel remains a declaration under the existing
append contract; no head/contact/motion permission or export is introduced. No
public request schema, cache/serialization or new controller route is added.
Later controller/job/replay binding must be implemented before that integration
can claim an actual complete later-cap pipeline.

## Budgets, invalidation and numeric environment

Reviewed aggregate work/cells and remaining child limits/time. Root callbacks
remain in every child cancellation/current path; packet callbacks and tighter
child caps are retained. Progress is polled before/after; final publication is
polled and revoked on failure. Tests cover caller source/list/limit replacement,
root and child cancellation/staleness, callback exceptions, rounding mutation,
deadline and limits below the observed successful work/cell totals. No partial
output survives. Existing bead failure counters are unavailable; reporting does
not pretend to measure them exactly. Callback preemption/RSS and general resource
containment remain separate unresolved obligations.

## Union pruning soundness and independent evidence

Reviewed nominal_bounds construction and the existing whole-run loss expansion.
An actual run is contained by its outward nominal enclosure. Lower coverage
requires the original expanded query in actual nominal material, so a query
outside that enclosure cannot be accepted by that one run. The run is retained
for union subdivision. Acceptance still invokes the same complete inequalities;
the enclosure cannot supply occupied/support material.

New tests check full partitions and independent 113-bit run/event inequalities.
A box contained in the enclosure but outside the rounded stadium refuses. Existing
gap/front/future-material and budget negatives must remain. The original steeper
source is explicitly refused at its unchanged transverse roof-error limit; the
additional shallow source is not a rewritten fixture/golden or relaxed policy.

Fresh selected CTest, independent final-byte/identity oracles, actual CLI and six
strict stock OFF/ZAA pairs are required in the milestone record. Full source,
curved/stepped interfaces, filled caps, allowable excess, seam/contact, full head,
whole-job order/geometry, all mandatory domains/software and physical publication
remain open. No complete B or physical qualification follows from this audit.
