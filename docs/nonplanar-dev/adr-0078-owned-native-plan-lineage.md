# ADR-0078 — bind the executed native dependency chain

Status: accepted for bounded software diagnostics; full B13 remains in progress.

A version-1 job manifest proves current byte association, not that its candidate
was derived from the native source. Public lower-level aggregates cannot provide
that producer guarantee. Execute existing algorithms from the protected job in
Analyzing/Planning workers and retain private immutable body/hatch products.
Require the private cap assembler's exact parent and entire body/selected cap
journal before accepting the actual linear planner and bytes in Serializing.
Only speed/acceleration reductions may change journal rows.

Use the same explicit non-slicing key registry for both publishable identity and
isolated derived configs, preventing raw credentials from entering derived config
hashes. Retain exact host settings for admission/invalidation. Every typed request
and actual generated hatch geometry enters the bounded lineage identity.

An optional protected plan adds manifest version 2 and its lineage hash. Keep
version-1 association and report version-1 shape/mandatory registry unchanged.
Full source-to-plan remains UNKNOWN/NOT_RUN: local affine construction and
journal preservation do not prove complete target, routes, geometry or resources.
No export/persistence migration, global mesh ordering normalization, secondary
planar engine, printer connection or user preset write is introduced.

Verification: five new native cases, 21/666 focused assertions, CTest419/419,
independent 5-positive/46-refusal report checks, CLI100 and strict OFF/ZAA6.
See B13-native-lineage.md and its separate author critical review. Independent
review, exact Linux source result, Windows, GUI/physical qualification and all
remaining full-job mandatory proofs stay pending.
