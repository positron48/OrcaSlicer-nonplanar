# B13 typed native job inputs: author critical review

The principal failure would be a job declaring one head/scene/flow/tolerance
while its actual candidate uses another. Typed capture accepts source-file roles
only; six exact resource roles come from privately owned parameter copies.
Changing geometry or a floating value without changing its ID/revision changes
its resource bytes and job hash. Comparison uses actual protected original and
planned inputs, not a caller boolean or imported report.

Typed candidate binding requires the protected native lineage in addition to
policy comparison. Body analysis compares exact original body parameters; native
plan lineage compares the complete original/derived journal and parent owners.
Cap producers legitimately increase calculated numerical coordinate error, so
base-model comparison preserves ID/growth/losses and the original minimum error;
exact native lineage determines the derived error. That partial comparison is
never sufficient to admit an unowned model. Mandatory source_model_plan_binding
still stays UNKNOWN/NOT_RUN because full source/target coverage is absent.

Replay option equality includes policy ID/revision, all three decimal tolerances
and both dose uncertainties. All inputs are copied before callbacks. A mismatch
produces no report. The current Verifying token can retry the original request;
no mismatched report exists to admit and no result grants export permission.
Candidate binding refusal invalidates its owning task as before. Worker body/
plan refusals remain local diagnostics and do not read or mutate a live Print.

Capture bounds share the original one-second deadline, 32 MiB aggregate bytes
and 256 resource count. Arrays are bounded before copying, all plain-double
encoding rejects nonfinite values, and scene arrays poll the same root guard.
Every begin invalidates its previous attempt first. Arbitrary callback exceptions
and late/reentrant capture refuse partial results without clearing a newer owner.
OFF bypass and legacy declared fixtures retain their existing behavior/format.

The Algorithms role currently captures serializer policy; derived reservation,
ROI/pass/hatch/assembly/contact choices are not all initial job inputs. Firmware
captures declared synthetic linear motion limits, not measured machine behavior.
Complete software linkage and installed/runtime resource provenance also remain
unqualified. New protected pointers cannot be reconstructed from imported JSON.
All fixed17 checks and export BLOCK remain. Independent safety review is pending;
this file is an author review. Exact runs and outstanding domains are recorded
in B13-native-inputs.md. No physical readiness is inferred from software tests.
