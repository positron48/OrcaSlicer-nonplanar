# B01 native configuration and fail-closed entry points

Invariant: an explicit nonplanar request, including an unknown mode or an
object/volume/layer override, must not silently enter stock slicing or publish
stock/cached G-code. OFF remains the legacy default. This is a bounded B01
implementation; it is not a working hybrid pipeline or export qualification.

## Contract and migration

`nptop_mode` is a namespaced string in PrintRegionConfig, default `off`. The
recognized requests are `safe_hybrid` and `strict_nonplanar`; every other explicit
value fails closed. Missing keys in older projects retain OFF. Keeping a string
rather than a forward-compatible enum prevents unknown future modes from being
silently substituted to OFF. No existing setting is rewritten. Config/project
serialization retains the key; stock G-code config comments omit default OFF to
preserve the pinned OFF/ZAA output. Existing region hash/equality and conservative
unknown-key slicing invalidation cover mode changes.

PolicySnapshot owns immutable copies of the checked resolved values and conflicts.
The preflight checks ZAA, firmware dialect, spiral, arcs, support/raft, wall
algorithm, fuzzy skin, ironing, scarf and post-processing, plus object/instance
counts. It reports exact conflicting keys/values. `passes_config_preflight()`
means only these checks passed; it is not a complete compatibility or safety
status. In particular `fuzzy_skin=none` means painted fuzzy skin in this base;
only `disabled_fuzzy` is accepted by this preflight.

## Native callers

Print validates the actual native object/region settings before slicing. The same
block is invoked at process, export_gcode, cached-file replay and GCode::do_export
before its existing-file fast path or any output creation. Explicit job mode
cannot be disabled by an OFF region override. Unresolved source overrides also
block publication rather than disappearing during resolution.

The BBS 3MF serializer rejects WithGcode in guarded mode before touching either
the destination or its temporary file. Plain source project saving remains
available. Backup saving omits embedded G-code while retaining original model and
settings. Network send entry points reject guarded requests before opening their
printer dialog/job. These guards are temporary fail-closed integration, not the
hash/revision-bound publication gate planned in B13.

## Limits and remaining work

The full compatibility registry (ORC-35), every motion-affecting setting, material
and measured firmware/scene qualification, immutable whole-job hashes/revisions,
GUI mode controls, and successful hybrid slicing remain unimplemented. UI/manual
network-route execution is not inferred from a source audit or a native build.
No profile has been qualified, no printer contacted and no G-code sent.

## Observed validation

macOS ARM64, Apple Clang 21, Release: application and both selected native test
executables built (exit 0). Eight B01 cases / 105 assertions passed with strict
NoAssertions; combined selected CTest executed 91/91 with no skips/failures. Four
isolated, network-denied CLI requests (safe, strict, unknown mode, safe+ZAA)
returned exit 205 with the gate diagnostic and zero G-code files.

Fresh flat/wedge/sphere OFF and ZAA captures all match the pinned G-code after
only the existing timestamp normalization, with identical modal XYZ/E/F/order.
The additive resolved-JSON schema field `nptop_mode: off` is the only settings
change. The comparator's explicit `--allow-nptop-off-default` flag permits only
that exact single line; every other byte stays significant. Goldens and G-code
normalization are unchanged. Five harness tests include changed flow, mode,
unknown setting and formatting rejections. This documented migration is why the
old expectation of byte-identical resolved JSON is no longer applicable to B01.

Initial compile failures were in test-fixture protected-state access and a Catch
INFO ternary; both were corrected without changing production access. The first
strict run reported two assertion-free SECTION bodies; the same two scenarios
now run as an explicit loop with their assertions. No negative scenario was
removed. Retained XML/log metadata distinguishes those attempts from final PASS.

Evidence: `evidence/B01/`; raw build/capture logs and G-code remain under
`build/nonplanar-evidence/`. Source and actual native binary hashes are recorded.
GUI interaction, physical tests, full registry and hybrid success remain NOT_RUN
or NOT_IMPLEMENTED as stated above. Linux run 36402596420 is still building
pinned dependencies at this checkpoint; it tests the earlier CI commit, not B01.
