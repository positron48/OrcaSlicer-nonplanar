# ADR-0074: final-byte complete run support and nominal gap bands

Status: accepted for the bounded synthetic component. Full B12 remains open. Parent ADR-0073;
normative SPEC/DATA_CONTRACTS remain unchanged.

An independently reconstructed actual continuous run must query only the actual
material completed before its first record. Adjacent packets of the same run
cannot falsely reduce the underlying-layer gap to zero at an internal cut.
Every actual packet keeps its decimal XYZ, current fraction and nominal width
from final E/flow/section. Its full conservative finite XY footprint is expressed
in longitudinal/transverse parameters, without a filled obstacle AABB.

The carrier surface passes through actual decimal endpoints. A separate explicit
synthetic policy declares its transverse slope and original vertical/normal
bands. Normal direction does not rotate the tool. Every accepted footprint tile
encloses all vertical/normal rays through the minimum inside empty nominal boxes.
Every normal maximum endpoint box is covered by the actual nominal union. Every
vertical maximum endpoint box is covered by the separate joined Lower union,
which also supplies a guaranteed geometric anchor and nominal terminal occupancy.
Together these bound first intersections for the complete actual footprint.
No declared section gap, prospective support plane or old planner certificate
can grant PASS. Original source error inflates queries, never new material.

Whole parameter partitions with protected source/run/cover owners grant positive
coverage. Unsupported boundaries refine within shared work/cells/depth/deadline,
or return UNKNOWN. Negative witnesses are restricted to points inside the actual
nominal target footprint and whole enclosed rays/endpoints; they cannot infer a
physical void from absence in Lower. A maximum endpoint below thin material may
conservatively refuse despite a valid first intersection. No physical band is
enlarged to make a terminal box fit.

This is an explicit synthetic affine carrier/common-run model. Cross-slope,
delivered-dose/contact/profile qualification and complete source/job/patch binding
remain separate. Per-event and external-front negatives remain. Full head/current
contact/cap/route/transform/order/export verification is not inferred. All guards
include original source/material/rate/join plus support-policy freshness through
positive and negative publication. Work is cumulative and all nested queries
share the original root deadline; exhaustion publishes no partial proof.

Protected nominal/run outer-box indexes only prune whole disjoint regions.
Each retained candidate still uses the exact section/erosion query. Index build,
sorting and traversal consume the same original work/deadline budget. They
cannot fill an AABB, skip intersecting material or grant Inside. This internal
owned representation adds no persisted IR/profile/3MF/cache format.

Analytical complete footprints and negative/guard cases pass. The complete
native eight-packet half-prefix remains UNKNOWN: the API exhausts the original
2,000,000 work budget, and its standalone all-stage replay exhausts the original
one-second deadline. No partial proof/witness is published. Query error remains
four times the original numerical coordinate allocation (.017448769336110316 mm
for this native case), with its full 3D allowance radius below the existing .05 mm cap. No error/loss/footprint,
physical band or negative test is reduced to manufacture a native PASS.
