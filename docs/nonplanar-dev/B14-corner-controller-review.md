# B14 captured corner controller: critical author review

Date: 2026-10-03. ADR-0101. This is an author audit; independent safety review
remains PENDING. It does not close B07/B13/B14 or Gate B.

The request captures the optional three-value repair policy before callbacks.
All binary64 bits and the original contour/fill recipe enter the job resource;
schema3 requires both the repair and an explicit later list. Existing empty and
later-only requests preserve schemas/bytes. Extra fields, bool/null quantities,
missing recipe/list, nonpositive gain and negative overlap refuse. The existing
schema3-without-corners negative now refuses for missing repair ownership rather
than unsupported version; it was retained, not removed.

The controller consumes real immutable factory output. Original cap generation
and repair share root work/cells/deadline; elapsed time rounds upward to avoid
restoring sub-millisecond time on restart. A positive test uses their measured
combined budget; limits sufficient for either operation alone refuse the whole
stage. Nested original precision/losses/boundary band remain unchanged. The
factory still proves every new finite strip against the actual original body.
Later passes receive the exact repaired first material prefix. Their support,
normal spacing/roof/width/dose/ordered ownership contracts are unchanged.

Native binding refuses repair omission, legacy jobs, one-bit policy edits,
changed contour/fill recipe and equal-content material with a foreign owner.
The private plan owns the original/final cap and exact candidate ancestry;
manifest5 binds the resulting material/motion/bytes, including optional later
lineage. Only the existing motion speed/acceleration reductions may differ.
Corner-plus-departure is explicitly unsupported; no unrelated route proof can
be applied to the changed endpoints. All public results stay blocked diagnostics.

Independent Python checks reconstruct exact ledger framing, preserve all old
deposited doses/sections, the full body and repaired first prefix, and parse final
decimal movement/E/byte ranges. Child/direct replay must match. Fifteen mutations
target policy, omitted/copied material, schema/list, movement/export, child input
and later prefix. The existing analytical corner checker remains separate.
These lineage/byte tools do not prove arbitrary sloped material unions or full
geometric safety. No planner collision routine is treated as an independent
oracle. Positive local results retain all thirteen unexecuted mandatory checks.

The controller's explicit .1 mm3 nominal overlap ceiling is simulation policy;
the earlier narrower .05 fixture is preserved separately. Standard U1 head and
.4 nozzle do not supply measured outer nozzle/head geometry. Firmware/material
brand information is not a prerequisite for this software work. GUI runtime,
new-source Linux/Windows, whole-job geometry and physical printing remain
unverified. Full seams/fill/contact/head/routes/order/source/software qualification
and atomic publication remain dependent work, with guarded export BLOCK.
