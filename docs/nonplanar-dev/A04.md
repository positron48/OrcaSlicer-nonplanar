## Implementation and review

`Nonplanar/Collision.hpp/.cpp` implements annular-tip/plane and translating
box/box queries using the A03 physical MotionEvent. Interval subdivision covers
the entire segment. The finite tip uses both transverse and longitudinal slope;
the opening radius never replaces the outer radius. Results carry event,
sequence, component and obstacle IDs, bounds, uncertainty and witness position.
The implementation is linked into libslic3r and called by native Catch2 tests;
there is no production planner consumer at this stage.

See `adr-0006-continuous-geometry.md` for the numerical domain and capability
matrix and `A04-critical-review.md` for the separate author review. The seeded
oracle found an early UNKNOWN that masked a later definite collision. The
corrected queue prioritizes smaller lower bounds. Its literal regression input
is retained alongside 300 independent slab-oracle scenes (seed 4704).
