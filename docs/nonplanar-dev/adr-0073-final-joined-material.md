# ADR-0073: independent final-byte continuous run lower solids

Status: accepted for an explicit synthetic common-run envelope only. Complete
B12 stays open. Parents: ADR-0055/0071/0072. Normative bundle remains unchanged.

Per-event lower erosion retains its meaning and original failures. A separate
protected common-run model owns the actual final-byte prefix and an explicit
policy. It reconstructs maximal adjacent deposition runs with exact XYZ endpoint
continuity, exact collinear forward XY and matching section kind. Every record
retains its own final E-derived minimum dose, affine top/gap and width; nothing
is averaged or merged into a replacement event. Travel/pressure/dwell, reversal,
turn or section mismatch breaks the run. No near-collinearity tolerance repairs
rounded geometry or consumes undeclared error.

Under this declared model, the lower run is the union of its actual minimum-dose
sections eroded by the unchanged local along/normal XY and Z loss/error kernel.
This is an explicit common-run shape envelope, not a deduction that independently
displaced finite packets must bond. It does not calibrate actual material/pressure
or qualify physical adhesion. Synthetic/confirmation/version/model restrictions
and a separate joined-policy freshness callback prevent claiming a measured model.

Whole query inflation crosses exact packet boundaries. Every complete positive
longitudinal slice must be inside its own minimum-dose rectangle/stadium. Closed
internal butt faces preserve continuity; genuine run ends, including an actual
partial current front, remain strict. Variable flux/gap/Z are reconstructed from
final bytes/declarations, never old run/support/clearance certificates. Unsupported
or uncertain sections cannot become PASS. Arbitrary exact collinear XY frames
are supported; curved or rounded zigzag turns remain separate runs.

A fixed admissible along, normal or Z kernel translation of the whole query
outside the minimum union supplies a negative erosion witness. This cannot
grant positive coverage. If neither complete inflation containment nor complete
translated exclusion is proved, subdivision or UNKNOWN retains uncertainty.

Typed joined snapshots/covers retain actual source, policy, complete run ranges,
regions and owner indices. All source/material/rate/join freshness, numeric,
work/cell/depth/deadline/cancellation guards remain through positive and negative
publication. Work inherits the complete prior prefix and capture. Query cover
partitions a region across qualifying runs; unresolved boundaries remain UNKNOWN.
Existing per-event APIs, outer collision envelopes, original margins/rows/IDs/
amounts, persisted IR/profile/3MF/fingerprints and blocked export are unchanged.
