# ADR-0097: captured ordered later paths in the common native controller

Date: 2026-10-03. Status: ACCEPTED_IMPLEMENTATION_IN_PROGRESS_FULL_B.
Parent: e139ae26e7ad4fe5eb3e01bd9939cefe8411662f. Follow-up to ADR-0096.

The ordered local factory previously had no owned controller request or native
job/replay binding. Capture a bounded immutable list of original pass index,
local XY footprint and candidate support plane. Every field and list order enters
the existing request hash, job resource, GUI input identity and child transport.

Empty lists preserve exact schema1 request bytes. Nonempty editing/canonical
requests use schema2 with later_paths rows [pass,min_x,min_y,max_x,max_y,plane].
Maximum4096 rows, pass ordinal0..15, finite/domain-bounded binary64 coordinates.
Schema2 requires a nonempty list; schema1 rejects that extra field. Pass0 and
geometrically invalid requests remain planner refusals. Old readers reject2.
The native-analysis-request-v1 resource slot keeps its established identity;
the contained document owns its explicit schema. No profile or 3MF migration.

Execute the ordered factory inside existing Material stage4; preserve all ten
controller/progress bytes and unchanged watchdog limits. Motion, serializer and
independent final-byte replay consume the actual final appended ledger. Root
current/cancel/deadline and tighter child work/cell/packet limits remain active.
No partial later result is published on interruption or unsupported geometry.

The private native plan adds schema3/later_lineage; candidate manifest adds
schema4/scope owned_native_body_cap_later_candidate_lineage_only. Earlier native
plan1/2 and manifest1/2/3 remain byte-compatible. The new identity owns exact
original/adjacent/final journal hashes, appended ranges, requests and path owners.
Native binding requires the complete captured schema2 program, refuses its
omission, one-bit request changes, copied material owners and unbound appended
material. Later plus the existing prospective-bead departure is unsupported;
that combination needs an actual complete route implementation.

A separate 1/8000 STL exercises genuine native execution without replacing the
original 1/16 source. The candidate support plane lies .035mm below the preceding
owned surface, within actual Lower material; normal/vertical/width/roof/error
limits are unchanged. Positive simulation execution declares initial acceleration
40mm/s2 under the original Z acceleration limit50. The original100 declaration
remains a final-byte AXIS_ACCELERATION_LIMIT refusal. This is an explicit slower
execution policy, not a changed verifier limit or proof of general quantization.

Scope: actual ordered local requests and byte/lineage integration only. Complete
filled later layers/cap, seams/contact, head/connectors/order/source/full job,
software/physical qualification and publication remain open. Mandatory report
still has17 checks; positive diagnostics have4 PASS/RUN and13 UNKNOWN/NOT_RUN,
overall UNKNOWN, export BLOCK. An original-rate refusal remains FAIL/BLOCK.
Independent safety review is pending; neither author review nor CI qualifies U1.
