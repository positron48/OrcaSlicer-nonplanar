# ADR-0064: owned complete simulation head/static scene/material motion

Status: bounded software composition implemented; measured qualification, contact,
whole job/replay/export and independent review remain pending. Scope: ProfileScene,
DepositionModel and both native consumers. Original normative files are unchanged.

## Invariant

A protected source owns the original declared simulation head/inventory, the
revalidated original material journal and the complete caller policy. Check every
original nozzle endpoint against the convex coverage domain once; no event is
rewritten or renumbered to fit the old Travel-only applicability API. The shared
scene-geometry predicate retains all six required head categories, unique IDs,
fixed-axis envelopes, moving-part all-configurations declarations, finite annulus,
complete inventory and omitted-upper-part coverage. Operator qualification claims
remain unsupported. Profile and material revisions have separate callbacks.

Capture all boxes and the tip as rigid components. Generate the first unused tip
ID; check all components against every static box with original event IDs/indices,
then against previous/actual-current Upper material. A complete successful source
and motion have private constructors. Passing a static result or a partial material
result alone cannot construct the combined certificate.

## Coverage and uncertainty

Material preparation now owns outward full Upper Z bounds for every original row,
including all potential partial fronts. Rectangles use the same top/bottom growth
as piece_interval; stadium tops/bottoms use the same enlarged radius, with shift
bounded by min(xy_growth/length,1). Nominal bottom endpoints are affine; a section's
width cannot raise its top. Future rows affect applicability only, never collision
occupancy at an earlier event. Refuse Upper material reaching the declared scene
ceiling: otherwise omitted upper head parts could collide with material beyond
that scene, despite all explicitly modelled components passing.

Coverage inflation includes original scene uncertainty, every caller uncertainty
and required clearance. Static pairs charge scene uncertainty twice for the two
envelopes; deposited-material pairs charge it once for the head, retaining source
Upper-model error and every caller term. Caller/source numerical error must fit the
original outward .05 mm budget. No uncertainty is discarded on an empty inventory.

The material component limit grows from 64 to 65 to accommodate the already
supported maximum of 64 head boxes plus the separately represented tip. Runtime
material-motion contract becomes 2; the new composed contract is 1. Existing
scene/geometry/serialized ledger/IR/3MF/profile/cache versions remain unchanged.
No current persisted cache or guarded export consumes these in-memory proofs.

## Continuous checks and publication

Reuse original primitive CCD for actual static box pairs and the material interval
partition for entire tool volumes against original sequential Upper. All queries
share total work and the original absolute deadline. Each static pair receives at
most the remaining work and its own bounded ceiling. The material proof receives
the remainder and outer cancellation/material/profile-revision callbacks. Recheck
at final publication. Pair exhaustion, missing bounds/proof, stale callbacks,
rounding changes, timeout or arithmetic/capture exceptions yield UNKNOWN with no
combined snapshot. Exceptions also clear already allocated successful snapshots.

Keep original source, event index, static obstacle/component IDs and material
row/time/tool witnesses on diagnostic results. Static boxes never replace actual
rounded material. A protected successful snapshot owns all static pair bounds
and the complete material proof for the same event and components. PASS applies
only to this captured declared simulation; complete machine/job approval is absent.

an interior duct collision, falling-current tip collision, incomplete inventory,
