# B14 common native controller: author critical review

The dangerous failure is publishing a mixed or partial result after a policy
edit, nested cancellation or internal phase transition. The controller consumes
one privately owned editing request, adds its exact canonical bytes to the job,
and passes only those captured values through each existing producer. Body and
hatch pointers originate from this current job, and lineage compares the exact
protected cap/journal/source/candidate before report binding. No imported PASS
or previous selection proof is admitted.

The one root guard latches exceptions from producer cancellation callbacks so a
nested diagnostic catch cannot clear them. Producers keep their existing bounded
work scopes, and every stage polls before/after progress and work. After phase
advance the guard adopts the actual current token. Binding has its own internal
phase transition; its cancellation wrapper must not retain the earlier token
wrapper. The implementation creates a fresh wrapper for that host operation,
then checks the actual returned token. Final report admission terminates the token;
no user callback follows it, and final root deadline checks are token independent.

Failed construction/analysis never returns a completed snapshot. Empty or oversized
run input starts a refused job capture to invalidate the previous attempt. Resource
copy size/name/count are bounded before copying. An older failure stops only its
own token and cannot clear a replacement created by a progress callback. Private
editing snapshot construction is not job execution or an admission credential.

The first cap is an explicit selected affine ROI. It is not full model cap fill.
The report still contains every unimplemented mandatory domain. Complete request
identity does not prove target coverage or physical scene/material/firmware state.
No file, CLI flag, GUI action, profile migration or export permission is added.
The shared controller is a backend prerequisite for those real entry points.

Untrusted interactive CGAL/native work is not exposed yet: cooperative limits
cannot substitute for process/RSS isolation. Separate cross-domain work accounting,
whole-job contact/seams/order/software qualification and independent safety review
remain open. This file records the author review, not independent approval.
