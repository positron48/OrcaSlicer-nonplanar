# B10 motion plan: separate author critical review

This is an author review of the actual implementation and evidence. Independent
Gate A/B critical review remains pending.

The protected source is captured before callbacks. The complete journal is
walked in its original order. Only XYZ ceilings decrease; pure-E pressure and
instant Travel preserve their original IR records and receive separate step
contracts. New raw rows do not carry trusted derived geometry: both existing
preparations rebuild/validate the full material and recapture the original scene.
Every source row remains represented. Canonical native comparisons allow only
the deliberately changed speed/acceleration fields.

Each axis and Cartesian/CoreXY drive uses a complete straight-segment interval
ratio. All XYZ and E rates/accelerations are bounded at the same peak path rate.
Nominal dose stays V; the command uses k once, and commanded-equivalent Q and
cross-section include k. Pressure amounts are checked separately and never add
nominal dose. Explicit pi bounds plus the original filament command enclosure
prevent point estimates from granting a rate guarantee. Empty directions cannot
trigger irrelevant reciprocal overflow because already safe rates need no divide.

The speed ceiling includes event frequency and sqrt(a*L); after reducing a by
rounding, recompute the triangular ceiling. This keeps v^2<=a*L for every exact
length enclosed by the interval. Rest-to-rest trapezoid timing covers the entire
event. Explicit full stops avoid unproved junction acceleration; firmware
lookahead is refused. Instant Travel requires dwell instead of an empty event.
These obligations must be implemented by the future exporter and independently
replayed; ordinary queued G1 commands do not enforce them by themselves.

Policy fields are owned and canonically fingerprinted. Source walks, axis/drive
checks, both preparations and final publication share one root work/deadline and
all three revision callbacks. Missing/malformed/unsupported profile or source,
cross-section/retraction/domain limits, work/records/deadline, stale/cancelled,
caller mutation and rounding refuse. Last-callback cancellation cannot publish
the private complete snapshot. No numeric/safety limit is relaxed.

Independent 113-bit arithmetic checks axes, CoreXY drives, E/Q/cross-section,
whole trapezoid time, total dose and filament. A diagonal needs twice the Cartesian
drive cap for the same source; a 0.0001 mm Travel slows for event frequency;
reducing Q slows the original complete source. Diameter and k tests detect wrong
area scaling/double flow. Pressure/dwell rows retain exact canonical values.
Native all-record comparisons and dose sums retain the original complete journal.

The missing header is the initial red. A second build was mistakenly launched
while the first was still active; it was interrupted. That overlap left four
library objects missing and the first archive command failed. The logs are kept.
After both handles were terminal, a single sequential build recovered the objects;
a final sequential rebuild forced current MotionPlan and both edited test objects.
Only the final build supplies test evidence. No failed build is used for tests.

Motion geometry/contact, complete native exit/access, full cap, firmware/flow
qualification and final bytes remain separate. CMake changes only register this
new source and give it strict interval flags/no PCH on all supported platforms;
stock source flags remain. Local tests and OFF/ZAA evidence are distinct from
current-source Linux, Windows, independent review and physical work.
