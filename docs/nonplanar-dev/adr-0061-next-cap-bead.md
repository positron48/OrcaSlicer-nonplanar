# ADR-0061: next finite-width bead above actual body/cap run union

Status: implemented bounded software primitive; independent review and complete
cap/motion qualification remain pending. Scope: DepositionModel, its independent
test oracle and both native consumers. Supersedes ADR-0060's unsupported
multi-run plane and actual later-bead boundaries. Original normative documents,
presets, losses, target and public export policy are unchanged.

## Invariant

A later bead derives its complete admitted footprint, gap and constant-flux dose
from the original later affine surface and the actual completed body/selected cap
prefix. A proposed run top supplies no roof lower bound until a protected whole
nominal occupancy certificate covers its complete plane. Original possible roof
upper bounds remain unchanged. Prospective surfaces and future packets never
certify support or occupancy.

## Whole run-union certificates

`cover_material_runs_lower` and `cover_material_runs_nominal` partition the whole
requested closed box into leaves with disjoint interiors. Each leaf is certified
inside one owned actual run; Lower expands it by the unchanged original losses
and coordinate error before certifying nominal occupancy. Lower may instead use
an original independent-event lower proof from the same actual prefix. This is
a union of separately eroded sets, not erosion of the whole union. Nominal uses
actual sections without model erosion and cannot be passed off as Lower support.

All runs and fallback events must own the same prefix. Actual current fractions
and real finite ends remain authoritative; internal cuts are closed and both
adjacent actual sections are checked. A nominal AABB only prunes. An independently
bounded outside point may refuse coverage, but no point sampling accepts a box.
Shared depth/cell/work/deadline/revision/cancellation limits include nested run
queries. Capture input handles before callbacks; publish only the complete proof.

`cover_first_cap_material_lower` retains its old one-run and body-only event
routes. A footprint requiring several cap runs retains the complete run/event
partition. This expands first-cap-support and first-cap-next-pass runtime contracts
to version 2. Material-run-union is version 1. First-cap-material version 1,
first-cap version 3 and persisted schemas/caches remain unchanged.

## Later bead construction

`plan_next_cap_bead` owns the assessed local original later cell, its support
certificate and exact body/cap assembly. It derives one straight X/Y centreline;
nominal width plus the admitted width error must fit the already supported parent
footprint. Exact affine interpolation and storage uncertainty enter the numerical
budget. The original complete target/ROI stays owned by the source.

First/later beads share private roof, segmentation and constant-flux amount
arithmetic. For a later query, candidate minimum actual tops are collected per run
over the queried longitudinal interval. Descending distinct candidates and bounded
downward offsets propose planes only. A whole nominal run-union certificate can
raise the existing lower roof bound; failure keeps the original supported plane
and leads to refinement/refusal. Unrelated transverse contour shoulders cannot
establish a floor. Successful proofs are retained with accepted roof segments;
failed-query cells/work still consume the common budget.

Every packet retains the original later vertical-gap policy, including effective
corner-height uncertainty, alongside unchanged default gap (.001 mm), width
(.005 mm) and amount (.001 mm3) error limits. The new next-cap-bead runtime
contract is version 1. Normal thickness, complete side-floor contact, head access,
order, speed/flow and physical bonding are separate obligations. This dose
snapshot is not an appended material prefix, complete later pass or export job.

## Verification and remaining scope

Independent 113-bit whole run/event boxes, exact leaf partitions, actual roof
sections and stadium integrals verify positive flat/sloped X/Y cases. Negative
cases retain real gaps/fronts, mixed prefixes, unsupported width/rounding,
perpendicular slope, shared budget/deadline exhaustion and publication callbacks.
The original native wedge preserves all 2034 body rows and 173 first-cap packets;
a .4 mm local support footprint spans multiple actual runs and supports an actual
.38 mm later bead of eight packets under the original later gap limits.

General 3D shoulder/seam deficit, allowable excess, whole later fill, exact
partial-body continuation, later material append/replay, normal/contact/head/order/
flow qualification and job/export integration remain pending. Software evidence
and historical failures are recorded in B07-next-cap-bead.md. Physical tests are
NOT_RUN; public guarded export remains BLOCK.
