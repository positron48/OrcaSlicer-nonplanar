# B07 retained infill densification: critical author review

Date: 2026-10-03. ADR-0102. Author audit only; independent safety review PENDING.

The factory owns inputs before callbacks and accepts only private complete caps.
It preserves all original packet pointers, target and original contour policy.
It rejects changed extents/variable widths and builds only parallel owners with
the original common longitudinal extent. A centreline is not treated as a finite
footprint: each new owner goes through the original finite-width actual-body roof,
gap, constant-flux packet and complete nominal fill construction.

Exact subdivision and stored-centre spacing checks prevent conversion rounding
from exceeding the selected pitch. The path limit bounds the subdivision loop
before allocation. Work includes old packets, sorting, body walks, new roofs,
packets and full joint integration. Retained packet/roof counts and errors consume
the new invocation's limits; retained volume error is subtracted before assigning
new dose allowances. Child deadlines deduct upward-rounded elapsed time.

The same complete final material proof measures covered gain, missing reduction,
added dose, repeated-material increase and complete spill. Both gain bounds must
meet explicit minimums, and added dose must be positive. Repetition is an explicit
simulation ceiling; the 2 mm3 analytical allowance is not physical calibration.
No gain is inferred just from adding paths. The real already dense native example
correctly refuses at the original .001 mm3 required gain.

Tests cover both axes/flat and actual nonzero slope, exact retained packets/doses,
actual reconstructed material, bounded work/cells/error, exact path capacity,
insufficient gain/overlap, missing input, path/work/cell/packet bounds, cancel,
stale input, deadline, changed rounding, callback exceptions, late cancellation
and repeated/legacy replans. The steeper coarse case retains its resource refusal.
Original numerical margins, precision and negative fixtures remain unchanged.

Independent rational stadium sections and disjoint rectangle sweeps bracket flat
unions. Mutation checks target retained packets, width/dose, pitch, target, gain,
overlap, union, axis and export. Sloped checks cover accounting/width only; they
do not independently prove arbitrary sloped unions. The native binder's explicit
densified-owner refusal prevents this new local result from being passed through
legacy native lineage. That new guard is source-reviewed; no positive native
densified assembly reaches it in this milestone, since the exercised native
candidate refuses for insufficient gain earlier.

First-cap private version6 defaults all existing factories to OriginalOwners.
Old complete-fill/corner witness readers retain historical versions. Existing
request, native-plan and manifest bytes are unchanged. Source identity invalidates
software-bound reports. Parent provenance distinguishes two private witness-version
changes from one software-bound report and the new analytical witness.

Captured density/controller/child/final-byte ownership remains the next dependency.
Complete target fill, seams, qualified contact/head/routes/order, whole job,
source/software/physical qualification and publication remain open. No printer
communication or preset writes were performed. Standard U1 head/.4 nozzle is known;
firmware/material-brand questionnaires do not block software implementation.
