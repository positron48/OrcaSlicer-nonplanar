CPU is user+system time from wait4 for that child; thread CPU may exceed wall
clock. Peak RSS is the OS high-water resident set, not macOS's separate footprint
metric, allocator totals or incremental library memory. A /usr/bin/time -l
cross-check of the 10000-move workload reported 30031872 bytes peak RSS.
Wall measurements include process startup, assertions, parsing and JUnit output;
no compiler run is timed. Cache state is not controlled, no warmup is discarded,
and the 5-sample range is descriptive, not a statistical confidence interval.

Workload sizes: contracts/geometry include 300 independent slab scenes and 2000
scaled-coordinate samples; native transitions slice one 12-facet wedge and two
12-facet terrace input meshes; serialization fixtures have three moves and 100
translated roundtrips plus mutations; profile fixtures contain one straight
motion. The stress workload has exactly 10000 moves and no CAD input.
Derived body facet counts are not used as an asserted benchmark input size.
