# B12 declared forming contact: separate author critical review

Author review only; independent safety review remains pending.

Permission is narrower than scene subtraction: only the finite flat working
face can interact with recent material from the same complete forward run.
The source coordinate test covers every padded world query point and every
front in a cell. Along growth is subtracted again when bounding nominal source
age. Collinear forward packet continuity is mandatory; otherwise the same
projection would not establish common age and the model refuses. A selected
packet cannot be omitted solely because it has a contact ID or because its
outer box overlaps the working zone.

The top-depth bound uses the whole recent source-height Lipschitz bound plus
original material Z growth/numerical error, with a positive limit below gap_min.
Full dose width and gap ranges are checked, not the nominal requested width.
This is an explicitly declared simulation assumption. It does not establish
physical compression/shear, temperature response, deposition calibration,
support, bonding or a successful filled surface. A future qualified model must
bound these domains and remain independently reconstructible from final bytes.

The face is zero-thickness and finite. Its annular geometry supplies the circle
bound when the working radius equals the outer radius. For a smaller radius,
only whole local boxes inside the working disk qualify. All six head roles,
moving envelopes, complete static inventory, every original margin and growth,
head/nozzle scene domain and omitted-part ceiling still apply. Pre-block material
and static objects remain forbidden even inside the working disk. Travel has no
contact path. Existing rigid APIs retain null contact behavior and exact outputs.

Current-material end-front enclosure is limited to the existing fixed
constant-flux, affine-gap model with nested prefixes. Negative samples use the
actual sampled front. Callers/model/options are copied before callbacks; root
budget and copied contact-current guard extend through publication. A stale,
cancelled, exceptional or unsupported floating environment cannot resurrect a
partial proof or a late negative witness. Protected factories own all inputs.

The independent 113-bit reference replays final text, reconstructs true-pi
dose/width/gradient/top bounds and permitted world-cell age, then validates
every other bead/head/static pair and partition coverage/measure/disjointness.
It does not call product geometry. Explicit finite reference guards remain;
rounded witness containment uses a complete common translated enclosure, not
one sampled center. The native hatch witness lies in the earlier contour and
the current hatch front is zero, so selected-run permission cannot hide it.

The first native selection used one contour side instead of the complete
contiguous block. Its expected refusal was retained, and selection was corrected
by expanding actual adjacent Deposit records. The resulting whole contour
still refuses at turns; no contact zone or margin was widened. A CLI preflight
used a wrong witness JSON key; its failure and corrected invocation are retained.

The strict diagnostic schema does not modify production profile/project/job
schemas. All reports remain job UNKNOWN/export false; the fixed 17 checks retain
13 missing domains. Broader support/contact, turns/seams/fill/order, full final
job geometry and qualification, Linux/Windows/full GUI/physical checks remain
explicitly incomplete. No preset, actual printer, cloud or normative file changes.
