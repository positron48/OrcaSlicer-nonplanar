# A06 — native serialization and independent text replay

Base commit: `cf816f0c`. Implementation commit: `git log --diff-filter=A --format=%H -- src/libslic3r/Nonplanar/GCodeAdapter.cpp`.
Scope: isolated GCodeAdapter, STL-only replay module, native Nonplanar tests,
CMake registration and development evidence. Shared GCodeWriter, OFF and ZAA
algorithms are unchanged. ADR-0008 defines the bounded experiment.

Invariant: ordered IR in already placed physical millimetres reaches the native
writer without nominal-layer Z addition, sorting, repeated XY offsets or extra
flow/slope multiplication. An independent parser observes the actual rounded
text, restoring omitted Z and modal F. The analytic fixture checks absolute
coordinates and V/(pi*d*d/4)*k for k=1 and k=1.17.

Positive geometry starts at (101,202,3), rises to Z=4.2344, retains that Z on
the next segment, then descends to Z=2. Layer labels decrease independently.
A further 100 translated cases include negative XYZ and a travel between beads.
Negative cases mutate XYZ/E/F/rounding, modal state and commands; broken order,
duplicate identity, discontinuity, unsupported retract and rounded-away motion
are rejected. The parser also bounds input bytes, line length and move count.

This is not a safety verifier or export path. The text comparison lives in the
native tests; no production sidecar, geometry replay, hash-bound report or gate
exists. Units, initial position, identity firmware transforms and acceleration
are simulation prerequisites, not operator confirmation. See the author review
in A06-critical-review.md; independent A08 review remains pending.
