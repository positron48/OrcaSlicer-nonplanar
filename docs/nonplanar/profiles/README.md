# Профили и их статус

Оба JSON в этом каталоге — **проектные данные нового модуля**, не stock Orca presets.

`generic_conservative_unverified.json` — синтетический пример: отверстие 0,4 мм, ненулевой торец и крупные условные оболочки. Все числа придуманы для проверки формы данных и симуляции. Это не универсальная безопасная голова; реальный обдув может выступать за любую из этих оболочек. Контактная модель не квалифицирована, экспорт для печати запрещён.

`printer_measurement_template.json` — форма для заполнения оператором. Null означает неизвестно, не ноль. Установленная голова, сцена, firmware state, скорости и материал требуют подтверждения. Этот документ не проходит как ready-to-print profile.

Будущий reference UM2 должен быть построен в задаче C03 по конкретным CAD-файлам/BOM, а не восстановлен по названию. Готового полного UM2-профиля в архиве нет. Будущие STL/SVG калибры строятся из текущего измеренного профиля; иллюстративные размеры здесь не подменяют измерения.

Схема проверяет структуру и некоторые связи. Взаимное положение, полнота coverage, строгий рост z в профиле вращения, orifice≤tip diameter, соответствие confirmation fingerprint и пригодность контакта проверяются runtime semantic validator. Установка одного флага operator_confirmed не делает профиль пригодным.
