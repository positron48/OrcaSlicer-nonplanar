# Аналитические STL-образцы

В `models/` — 10 замкнутых геометрических образцов. Параметры, формулы и сетка в `catalog.json`; hashes, размеры и объём треугольной модели в `models/manifest.json`.

Они созданы входами для экспериментов и тестов. Это **не G-code**, не проверка коллизий и не обещание пригодности к печати на конкретной голове. Тесселяция с фиксированной сеткой не гарантирует универсальный chord tolerance; отдельные accuracy tests должны сравнить её с формулой. Особенно это важно у крутого основания tall_dome.

Из корня комплекта: `python3 scripts/generate_fixtures.py`. Повторная генерация меняет только перечисленные STL и их manifest; при редактировании параметров обновить контрольные суммы всего комплекта осознанно.

Полные fixtures системы дополнительно включают профили головы/сцены/материала, ROI и независимые expected values. Сцены с отверстиями, узкой впадиной, высокой стеной и STEP-единицами — задачи разработки, не заявлены готовыми здесь.
