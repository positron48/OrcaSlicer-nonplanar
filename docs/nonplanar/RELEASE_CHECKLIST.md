# Приёмка экспериментального релиза

Все пункты здесь **не выполнены на момент выдачи ТЗ**. Проверки самого архива отражены отдельно в reports/package_qa.json.

## База и сборка

- [ ] Зафиксированы upstream/fork SHAs, зависимости, схемы, compiler/SDK и licenses.
- [ ] Собраны и запущены macOS ARM64 и Linux x86_64; CTest действительно выполнил требуемые tests.
- [ ] Экспериментальная сборка имеет отдельные app/config/cache identity; stock установка не повреждена.
- [ ] Runtime slicing и проверка не требуют сети/платного API.

## Полный функциональный путь

- [ ] STL и STEP проходят units/topology/tessellation validation; исходник сохраняется.
- [ ] Planar body генерируется Orca, крышка не дублирует исходный объём.
- [ ] Реальная ступенчатая основа, переходные слои и несколько patches поддержаны.
- [ ] Конечный торец, полная голова, сцена и sequential material учтены.
- [ ] Проверены вверх/вниз/поперёк склона, все переезды/выходы/парковка.
- [ ] V→E, flow application, осевые и firmware extrusion limits соблюдены.
- [ ] 3MF round-trip и нативный sequential preview работают.
- [ ] Генератор калибров использует активный profile hash и учитывает fit tolerance.

## Проверка и выдача

- [ ] Независимый parser/replay проверяет окончательные bytes после всех разрешённых фильтров.
- [ ] Mandatory FAIL/UNKNOWN/NOT_RUN блокируют экспорт; пустой отчёт не проходит.
- [ ] Все file/CLI/removable/3MF/cache routes протестированы; сеть/автозапуск hybrid отключены.
- [ ] Snapshot changes, late callback, mode toggle и новый профиль аннулируют verified state.
- [ ] Подтверждена атомарная публикация, recovery и hash после копирования.
- [ ] Нет заглушек или bypass на путях PASS/export.

## Регрессия и полезность

- [ ] OFF и ZAA совпадают с закреплённым stock baseline в согласованной области.
- [ ] Положительные fixtures реально печатают ожидаемую непланарную область.
- [ ] Все обязательные отрицательные/mutation tests обнаруживают внесённые нарушения.
- [ ] Есть independent analytic oracles и сохранённые seed контрпримеров.
- [ ] Измерены performance/memory; лимиты не обходятся снижением точности.

## Физические результаты и передача

- [ ] Измерен и подтверждён хотя бы один реальный profile, его геометрия и калибры.
- [ ] Выполнены контролируемые испытания и три последовательных успешных экземпляра трёх форм.
- [ ] Выпущен отчёт сравнения с обычной печатью/ZAA, без неподтверждённых обещаний.
- [ ] Известные ограничения, допустимые settings/materials/slopes документированы.
- [ ] Переданы исходники, сборки, fixtures, test evidence, инструкции, профили, schemas и licenses.

Нельзя отметить весь релиз выполненным только потому, что отдельные unit tests или helper scripts прошли. Невыполненный физический этап оставляет статус «software candidate, physical qualification incomplete», а не «готово к безопасной печати».
