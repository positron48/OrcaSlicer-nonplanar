# Выполненные проверки комплекта

`package_qa.json` фиксирует область проверки, `helper_tests.txt` — фактический журнал 25 тестов вспомогательных Python-скриптов. Проверены генерация и структура STL, аналитические объёмы плоского блока/клиньев, контрольные суммы, связи документации, граф задач, схемы примеров и обработка ошибок вспомогательных инструментов.

Скрипт аудита исходников проверялся на **искусственных временных Git-репозиториях**. Закреплённые исходники Orca выборочно изучены через web; реальный локальный checkout не собран и локальный аудит на нём не выполнялся.

**125 сценариев в acceptance_tests.csv — план будущих тестов системы.** Здесь нет реализации непланарного слайсера, результатов его запуска или физических испытаний. Статус PASS документационного пакета не означает безопасность движения принтера.

Повторить проверки из корня комплекта:

```sh
python3 scripts/validate_package.py --json-schema
python3 -m unittest discover -s scripts -p 'test_*.py' -v
```

Для первой команды с флагом `--json-schema` нужна необязательная библиотека `jsonschema`. Без флага базовые проверки работают на стандартной библиотеке Python 3.10+.
