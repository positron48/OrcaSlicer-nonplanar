# Статус схем

Версия всех контрактов — `0.1.0-draft`. Это самодостаточные JSON Schema draft 2020-12 для включённых примеров. Они фиксируют согласованное начало разработки, не заявляют завершённый runtime формат.

Профиль пока описывает осесимметричный наружный профиль сопла и боксы остальных компонентов. Производственный формат в задачах B/C должен добавить проверенные цилиндры/конусы/оболочки/mesh references и миграции, если эти представления нужны. Не делать универсальный «любой JSON» ради пропуска отсутствующей геометрии.

Schema validation не проверяет непрерывные коллизии, порядок слоёв, физические измерения, полноту mandatory registry или соответствие E материалу. Эти инварианты описаны в SPEC/DATA_CONTRACTS и требуют semantic validator. Нулевой hash в примере — явный placeholder, не hash реального файла.
