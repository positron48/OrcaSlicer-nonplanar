# Матрица совместимости первой законченной версии

Это **политика нового guarded-hybrid режима**, а не описание ограничений штатной Orca. OFF/ZAA сохраняют upstream-поведение без присвоения нового статуса проверенного задания.

| Функция/условие | Guarded hybrid P1/P2 | Обоснование/приёмка |
|---|---|---|
| Cartesian / CoreXY, неподвижная ориентация сопла | Да, по измеренному профилю | Полная голова, сцена и axis limits |
| Klipper | Единственный выходной firmware contract | Ограниченный dialect и известные transforms |
| Delta, belt/infinite-Z, наклонные оси | Нет | Иная кинематика/сцена вне объёма |
| Одна модель, один instance, одна пластина | Да | Число solids после импорта/объединения фиксируется |
| Несколько верхних patches одной модели | P2 | Проверенный порядок и доступность |
| Несколько моделей/копий, печать по объектам | Нет | Взаимные препятствия и порядок вне начального объёма |
| Одна голова/одно сопло/один материал | Да | Без toolchange и AMS/пурж-башни |
| STL | Да | Units и topology validation |
| STEP/STP | P2-квалификация существующего импорта | Units, assemblies, tessellation/round-trip |
| Uniform planar layer height | Да | Переменная высота вне первой матрицы |
| Fixed line width / обычный wall generator | Да | Не включать переменную ширину без отдельного контракта |
| Число периметров, rectilinear infill density | Да | Resolved параметры, плотная подложка под крышкой |
| Разные рисунки infill, variable-width/Arachne | Не квалифицированы | Не добавлять варианты до базового результата |
| Native ZAA вместе с новым режимом | Нет | Запрет двойной деформации/экструзии |
| Scarf seams, ironing, fuzzy skin, spiral/vase | Нет | Дополнительные преобразования траекторий |
| Supports/raft/bridge в новой задаче | Нет в P1; P2 также без генератора поддержек | Неподдерживаемая опора → отказ, не печать в воздухе |
| Skirt/brim/прайминг | Только явно проверенный ограниченный вариант | Весь материал и head travel входят в scene/replay |
| Arc fitting / G2/G3 / binary G-code | Нет | Первая версия сериализует проверяемые линейные команды |
| Z-hop/retract/wipe | Только контракт нового plan | Никакого дополнительного штатного wipe после проверки |
| Flow ratio, PA, input shaping | Фиксированные/откалиброванные и внесённые в контракт | Не умножать E дважды; физическая квалификация отдельно |
| Adaptive PA/динамические flow-компенсаторы | Нет до отдельного аудита | Неизвестное изменение E не допускается |
| Cooling/minimum layer time | Только проаудированный фильтр до verifier | Финальные F/команды пересчитываются и проверяются |
| Bed mesh/skew/offset | Identity или отдельно реализованный fixed transform | Нельзя проверить commanded path и забыть физический |
| Пользовательские G-code macros/scripts | Нет произвольных | Известный ограниченный пролог/эпилог, trust boundary |
| Post-processing script из preset/3MF | Не исполнять | Не даёт обход gate/выполнение shell |
| Object/region override | Те же ограничения после resolution | UI-lock недостаточен |
| Отправка/печать по сети/cloud | Отключены только для guarded hybrid | Экспорт файла вручную после проверки |
| Обычный 3MF проект | Да в форке | Namespaced state, unknown schema policy |
| Sliced 3MF / embedded G-code | Только валидированный payload; иначе запрет | Нет непроверенного candidate в архиве |
| Новый/неизвестный transform-setting upstream | Запрет до аудита | Нельзя молча наследовать опасное поведение |

Реализация хранит machine-readable policy и диагностирует точные конфликтующие значения. Не переключать пользователя на другой материал, слой или рисунок заполнения без видимого согласования. Отказ из-за несовместимости не стирает исходный профиль.

Пределы наклона, размеров крышки, локальной толщины и скорости определяются сочетанием профиля/геометрии/проверок; фиксированное «до 45°» не является универсальным допуском. Пологий уклон рядом с высокой стеной может быть недоступен.
