# Задание на один модуль

Выполни следующую готовую по зависимостям задачу `<TASK_ID>` из `docs/nonplanar/backlog.json`. Прочитай связанные SPEC sections, DATA_CONTRACTS, safety policy и test IDs. До кода сформулируй invariant, вход/выход, разрешённые изменения и independent oracle.

Добавь положительный и отрицательный tests, реализуй минимальный рабочий путь внутри C++/GUI Orca и выполни tests. Shared changes требуют OFF/ZAA differential. Не ослабляй checks, не удаляй failed fixture и не переводь UNKNOWN в PASS. Статус не меняется на done по наличию файлов/компиляции без реального вызова.

Передай commit, точные команды/exit codes, количество выполненных tests, артефакты, риски и NOT_RUN. Используй templates/TASK.md и TEST_RESULT.md. Не подключай реальный принтер.
