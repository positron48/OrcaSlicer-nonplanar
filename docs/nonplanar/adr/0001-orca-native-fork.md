# ADR-0001 — нативный форк Orca

Статус: принято как проектное решение; реализация не выполнена.

База — закреплённая Orca, C++17, нативный GUI и обычный planar engine. Не создавать второй slicer/UI и не использовать внешний PrusaSlicer как основную архитектуру. Headless verifier и аналитические Python tools допустимы.

ZAA сохраняется отдельным baseline. Guarded hybrid использует typed absolute-XYZ/volume IR и не запускает ZAA на тех же путях. OFF/ZAA regression обязательна. Новый runtime module не импортирует GUI.

Следствие: экономится самостоятельный интерфейс и планарный движок, но необходимы аудит большого конвейера, consumers 3D paths, фильтров, состояний и всех экспортных маршрутов. Точные hooks устанавливаются A02/A06; изменение основы требует нового ADR.
