# ADR-0004 — изоляция и обновление базы

Статус: принято как проектное решение; реализация не выполнена.

Экспериментальная сборка использует свои app/config/cache identity, не изменяет рабочие presets пользователя и не синхронизирует новые поля в cloud. Stock auto-update не заменяет fork. Удалённый git fork создаётся/публикуется владельцем, не подразумевается наличием архива.

3MF расширяется namespaced записью; исходная модель не заменяется derived body. Stock Orca может игнорировать/утратить расширение; сохранение нового verification state в stock не обещается.

Обновление upstream требует отдельной ветки, source audit, rebuild, OFF/ZAA/hybrid regression, миграции схем и повторения affected physical qualification. Изменение SHA без evidence не делает старые отчёты актуальными.
